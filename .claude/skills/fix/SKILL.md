# fix skill

현재 작업 디렉토리 내 코드를 전수 검사하고 수정한다.  
범위는 스킬을 실행한 폴더 안으로 한정한다.

## 실행 순서

### 1단계: 범위 확정

`pwd`로 현재 디렉토리를 확인한다. 이 경로가 모든 검사의 루트다.

### 2단계: 빌드 검증

레포 루트에서 `./gradlew build -x test`를 실행해 컴파일 오류를 확인한다.

오류가 있으면 파일을 직접 읽고 수정한다. 수정 후 재실행해 오류 0을 확인한다.

### 3단계: 테스트 실행

`./gradlew test`를 실행한다.

실패한 테스트가 있으면 원인을 파악해 수정한다. 테스트 의도가 불명확한 경우에만 사용자에게 묻는다.

모든 수정 후 재실행해 테스트 통과를 확인한다.

### 4단계: CLAUDE.md 규칙 검사

현재 디렉토리부터 레포 루트까지 모든 `CLAUDE.md` / `claude.md`를 수집한다.  
각 파일에서 코드 규칙(금지 사항, 설계 규칙, 컨벤션)을 파악한다.

파악한 규칙을 기준으로 범위 내 소스 파일을 검사한다.

**CLAUDE.md 규칙 위반은 반드시 수정 전에 사용자에게 확인을 받는다.**

위반이 여러 개면 파일별로 묶어서 한 번에 보고한다:

```
[CLAUDE.md 규칙 위반 발견]

파일: devnews/api/src/main/java/com/devnews/api/ArticleController.java
  • 12번째 줄 — 서비스 레이어 미경유 직접 레포지토리 호출
    현재: articleRepository.findAll()
    권장: articleService.getAll()

수정할까요?
```

동의하면 수정, 거부하면 다음 파일로 넘어간다.

### 5단계: 완료 보고

```
✓ 빌드: 오류 0
✓ 테스트: N개 통과
✓ CLAUDE.md 규칙 위반: N개 수정 / M개 건너뜀
```

발생하지 않은 항목은 생략한다.
